# 动画调速 Mod

面向 Summertime Saga v21，复现原版（v0.20.16）风格的动画速度控制。当前仓库使用的匹配游戏版本为 `21.0.0-wip.7944`。

## 功能与使用

在动画场景的选项栏两侧添加“慢一点”和“快一点”按钮，点击后逐档调整动画速度：

| 档位 | 速度 |
| --- | --- |
| 慢 | 0.67 倍 |
| 稍慢 | 0.83 倍 |
| 标准 | 1.00 倍 |
| 快 | 1.25 倍 |

默认使用标准速度，到达最慢或最快档时，对应按钮禁用。进入或离开场景选项菜单时恢复为 1.00 倍；速度选择不写入存档。当前不显示速度状态文字。

按钮在简体中文模式下显示中文，其他语言下使用英文后备文字。脚本调整动画缓存中的帧率，不改变剧情进度或对话文字速度。

## 安装与更新

- 使用本仓库构建的汉化包时，Mod 已随包包含，无需另外安装。
- 使用仓库源文件时，将 `mods/sex_speed_control/` 文件夹复制到游戏的 `game/mods/` 目录；也可以将整个 `mods/` 文件夹复制到 `game/`。
- 单独安装时仅需 `sex_speed_control.rpy`，目录为 `game/mods/sex_speed_control/sex_speed_control.rpy`。

安装或更新前完全退出游戏。旧版曾安装在 `game/`、`game/tl/zh_hans/` 或 `game/mods/` 根目录的同名脚本及 `.rpyc` 应先移除，避免重复加载。不要同时使用内置此 Mod 的汉化包和散装脚本。

## 卸载与兼容

完全退出游戏后，删除 `game/mods/sex_speed_control/` 中的脚本及编译文件；包内版本需通过更换不包含此 Mod 的汉化包来移除。

此 Mod 重定义原生 `lewd(items)` 屏幕，并依赖 `saga.display.anim.cache` 及动画对象的 `fps`、`update()` 接口。游戏调整这些接口或场景菜单布局时需要重新适配，不能保证所有未来版本兼容。
