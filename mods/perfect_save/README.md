# 完美存档Mod（运行时构造）

每次点击均由正在运行的游戏自动生成原生存档，不附带预制存档，不转换其他版本的存档，也不选择按版本号准备的模板。构造任务完成状态及图鉴记录，不代表实际播放过所有对白，也不伪造已阅读记录。采用预览模式的金钱和属性加成。

## 安装与使用

将本目录的三个脚本`perfect_save.rpy`、`completion_state.rpy`、`reacquisition.rpy`一起放入`game/mods/perfect_save/`，重新启动游戏。中文界面需同时安装对应版本的汉化资源。旧安装如含`perfect_template_data.rpy`及其`.rpyc`，请删除这两个退役文件。

在**读取**界面点击右上角五角星，立即覆盖固定的`quick-6`，第1—5格不轮换，保存界面没有此按钮。短说明和通知随英文／中文语言切换，存档卡片显示“构造存档”／“Constructed save”。版本号只保留为原生存档元数据及诊断证据，不作为生成或读取的限制条件。

- 点击时仅生成：不读取、不传送、不改变当前游戏状态或当前图鉴。即使玩家正在其他场景，生成档也使用独立的新游戏上下文。
- 读取生成档后停在第1天首时段、主角房间；原生按日期累计的活动戳从登记回调识别并补入此前一周历史，保留随机NPC、时段、占用和每日冷却规则。姓名Anon，现金100000、银行9990000、四项属性10；不会回到点击时的场景、对白或回滚历史。
- 使用当前引擎的原生默认状态和新游戏初始化，遍历本版注册的编号任务、一次性程序与NPC节点，不要求任务必须有done清单；应用已解析的完成状态及重复内容入口。根据原生事件池、完成标记和提示识别当前最后任务中的后续更新占位节点，保留其终点；旧占位节点被更晚任务取代时不再强制停在旧节点。不会创建本版不存在的节点或开放未实现地点。
- 生育周期从本版注册的产后回调、原生重置接口和返回阶段识别：对已实现关系构造已生育一子并恢复的终态，保留回家记忆和历史孩子数，结束当前孕期及本轮监听。重复互动由任务完成回调注册的原生程序发现，不维护角色或事件入口清单。编号任务完成不等于这些独立后果已写入。
- 联系人按当前版本具有身份分类、头像、原生资料字段及资料页立绘的角色补齐。有头像但无`info`、背景等资料的一次性角色不加入联系人；不编造档案。读取此前构造档时自动清理这类无效联系人，若手机停在无效资料页则退回联系人列表。检查本版任务及重复事件回调中的原生地点开放调用，使用地点自身的`open()`接口开放；只标记任务完成不会自动产生这些后果。
- 背包列出本版所有具有库存图标的可携带物品，包括钥匙、卡片、工具和服装，每个目录对象仅一份。已交付给角色或装入设备的物品仍以同一个对象列入背包，保留原生交付／装备归属，避免破坏剧情后置条件；这是构造库存，不代表正常通关时实际剩余的物品。生成前记录原生场景位置，商品使用原生库存登记位置，完成剧情后的交付不丢失原场景展示。
- 生成时依原生优先级先调用NPC每日reset，再调用移动及场所状态回调，补齐每日工作状态、人物位置、服装及场所标签；未知重置调用、动态参数或循环会停止生成。不执行任意剧情回调。登记原生未来剧情终点到提示列表，并停用已完成世界的地点首次到访介绍及开场监听，不伪造对白已阅读记录。原版营业时间、未实现角色及场所仍保留原规则。
- 地点独立初访程序按本版原生`clear`结束协议处理：仅接受纯展示脚本及已核对的存在性检查，注销其观察者和临时访问限制；含未知调用、状态写入或动态脚本的程序不按此规则处理。无需为单个地点另设开门标志。此前遗漏这类结束状态的构造档须更新后重新生成。
- 读取时导入当前版本注册的图鉴场景。保留已有解锁时间、偏好与`persistent.cookies`开关，新增构造记录单独登记在`persistent._ssct_constructed_gallery`，不计作正常游玩获得。
- 图鉴写入persistent后会持续保留，不随图鉴Mod的临时作弊开关取消而撤销。

在构造档中，场景里的物品仍可点击收集，商品仍可放入购物篮；成功收集或加篮后，唯一物品从原场景撤下。动作使用原生移动及进入／离开事件，结账继续执行原生确认和转移，金额为0、不扣款，背包不会出现第二个唯一对象；有价商品显示购买，原生免费借阅仍显示借阅。放回或未确认加篮不撤下展示；取消结账、离店弃篮按原版退回库存，背包里的预拥有记录保留。物品价格本身不改写，普通存档沿用原价。非唯一物品的补货与数量行为由原生协议处理，不为每件道具编写补丁。

完成状态按原生程序分析：从编号任务、角色阶段及设备状态机提取可识别的关系记忆、交付物归属、成绩、日记和事件注册，继续遍历完成后注册的程序；从本版脚本AST读取静态菜单返回值和初次见面条件，沿可确定的原生重置／设备转移进入稳定状态。写档前验证已解析的后置条件。无法分类的字段写入记录在completion_contract中，不当作已解决；无法确定的产后终点停止生成。此分析不执行全部回调，也未完整求解所有动态条件及互斥分支，不能据此认证全支线或未来版本全部玩法。

展示仅用于本Mod生成的存档，采用本版原生图层顺序、时段及标签筛选；原包没有对应场景图层的物品不会凭空增加图像。背包和场景引用同一个原生对象，陈列记录及消耗状态随存档保存；不复制道具。已交付物也可列入背包和已有的原场景展示，但不会在生成时移走原生交付／装备对象。旧构造档须更新Mod、重启并重新生成，才能获得本轮完整库存及展示消耗规则。

## 兼容与验证

生成在临时原生上下文中执行，完成后恢复玩家的存储变量、执行上下文、回滚日志及随机数状态。生成异常在槽位写入之前退出；最终通过Ren’Py原生SaveRecord签名和存档接口写入，不调用QuickSave。

不按版本号禁用功能。任务、角色、图鉴及截图均取自运行引擎；根据对象实际字段适配NPC的flow存储或角色存储，任务编号支持三位及更多位数。缺失的可选对象／重复入口跳过，不伪造旧节点别名。完成后果使用原生程序结构及已有接口协议，不按角色名追加事件修复；未来新剧情采用新结构或接口时仍需检查，自动识别节点不能保证尚未发布版本的全部玩法。

旧实现遗漏地点开放、物品归属、NPC日程、未来剧情提示或Maria产后重复互动的存档仍需重新生成：更新Mod并重启后，再点击五角星生成、读取新的quick-6。本轮无效联系人清理随更新后的Mod读档生效，无须专为联系人报错重新生成。

## 卸载

退出游戏后删除`game/mods/perfect_save/`；使用RPA时移除含此Mod的RPA或换用不含它的补丁。按钮及读档导入功能随Mod移除，已经生成的存档和persistent记录仍保留。生成档含本Mod的恢复标签，继续读取这些存档时应保留Mod。
