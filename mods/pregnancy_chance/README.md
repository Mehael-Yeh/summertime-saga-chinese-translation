# 怀孕概率 Mod

在设置→游戏选项中添加“怀孕概率”，位于“难度”和“显示受孕结果”之间。使用左右箭头循环切换五档，默认1x；倍率为全局偏好，重启后保留，对之后的受孕尝试生效。

| 档位 | 效果 |
| --- | --- |
| 0x - 内射不怀孕 | 原生受孕判定不产生怀孕；可能阻断需要怀孕才能推进的任务 |
| 0.5x - 一半怀孕概率 | 原版概率乘0.5，仍然可能怀孕 |
| 1x - 原始怀孕概率 | 完全沿用原版判定 |
| 2x - 双倍怀孕概率 | 原版概率乘2，最高100% |
| ∞x - 必定怀孕 | 原版允许受孕时必定成功；已怀孕等原生限制依然有效 |

鼠标停在当前档位或左右箭头上，在最右侧箭头按钮的右边显示本档说明；始终使用该按钮的实际显示位置定位，不随鼠标位置或当前悬停控件改变。提示沿用“显示受孕结果”的框体尺寸及偏移风格，使用不透明底色和独立顶层显示，避免被设置控件遮挡，移开鼠标后隐藏。支持英文和简体中文。0x提示明确提醒任务后果；若任务需要怀孕，请切换到其他倍率后重新尝试。切换倍率不会撤销已经发生的怀孕，也不会补发此前失败尝试的结果。

显示或隐藏受孕转盘均使用同一倍率；保留原版孩子类型分配、后续孕期和剧情处理。此Mod只调整本版已有的受孕判定，不新增角色的生育剧情，也不缩短孕期。概率封顶与必定成功仍不绕过场景是否调用受孕判定等原生条件。

## 安装与卸载

退出游戏，将本目录复制到`game/mods/pregnancy_chance/`，所需脚本为`pregnancy_chance.rpy`。使用包含此Mod的汉化包时不必再安装散装脚本，以免重复加载。

退出游戏后删除本目录内的`.rpy`和`.rpyc`即可卸载；包内版本需更换不含此Mod的汉化包。原版角色概率字段不写入倍率，卸载后恢复原生判定。已经发生的怀孕及剧情后果保留。

## 兼容与验证

依赖原生`saga.obgyn.Womb.next`的概率、孩子类型及孕期协议，通过插入设置行扩展原生设置屏幕。其他Mod若替换同一判定或设置结构，需要另行检查。未来游戏版本更改接口时可能需要适配。

原生验证结果和具体覆盖范围记录在`translation_context/progress.md`。完整任务游玩与其他未测平台不继承局部概率及界面检查的通过结论。
