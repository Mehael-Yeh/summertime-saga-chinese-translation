# 角色图鉴一键解锁 Mod

已核对版本：Summertime Saga `21.0.0-wip.7944`。以兼容后续版本为目标：只要原生 `cast` / `lewd_menu` 屏幕、Ren'Py 屏幕注册接口和 `persistent.cookies` 全解锁语义保持兼容，就无需跟随角色或场景数量更新脚本。未来未发布版本无法提前保证。

在 Cookie Jar（角色图鉴）的角色列表和角色场景界面右上角添加打开的锁头图标。点击后，所有角色入口、场景和变体使用游戏原生的全解锁模式，界面立即刷新，并保存到当前用户的持久化数据中。无需载入剧情存档，不推进剧情任务。

## 安装

使用本仓库完整汉化源文件时，此 Mod 随 `tl/zh_hans/` 一起安装；后续构建的汉化包也会包含它。

单独安装时，把 `tl/zh_hans/cookie_jar_unlock.rpy` 复制到游戏的 `game/` 目录。不要同时保留两份该脚本。

首次打开图鉴时，先关闭游戏原有的介绍弹窗，再点击右上角锁头。

## 持久化行为

Mod 设置原生的 `persistent.cookies = True`，不伪造已看过场景的记录。卸载脚本会移除按钮，但不会撤销已经保存的全解锁设置。游戏原有的隐藏/替代场景组织规则继续生效；尚未制作的内容不会因此新增。

脚本保留原生屏幕定义及各设备变体，仅在原界面绘制后附加按钮；不维护角色名或场景 ID 清单。点击时检查图鉴接口，接口缺失时提示不兼容且不修改解锁数据。若未来更改屏幕名称，按钮可能不再出现；若保留字段却改变其语义，仍需重新适配。
