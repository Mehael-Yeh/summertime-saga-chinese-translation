# 角色图鉴一键解锁 Mod

已核对版本：Summertime Saga `21.0.0-wip.8194`；7944的一键解锁曾单独验证，本次新增切换功能的验收以8194为准。只要原生 `cast` / `lewd_menu` 屏幕、Ren'Py 屏幕注册接口和 `persistent.cookies` 全解锁语义保持兼容，就无需跟随角色或场景数量更新脚本。未来未发布版本无法提前保证。

在 Cookie Jar（角色图鉴）的角色列表和角色场景界面右上角添加切换按钮。正常解锁状态显示开锁图标🔓；点击后启用原生全解锁模式，图标变为闭锁🔒。再次点击闭锁按钮关闭全解锁，恢复正常的剧情解锁状态，图标变回🔓。两次操作都会立即刷新界面并保存，无需载入剧情存档。

## 安装

使用本仓库源文件时，将 `tl/` 和 `mods/` 复制到游戏的 `game/` 目录；后续构建的汉化包也会包含此 Mod。

单独安装时，把 `mods/cookie_jar_unlock/` 文件夹复制到游戏的 `game/mods/` 目录，脚本路径为 `game/mods/cookie_jar_unlock/cookie_jar_unlock.rpy`。不要同时保留两份该脚本，也不要同时使用内置此 Mod 的汉化包和散装脚本。

更新前完全退出游戏，移除曾放在 `game/`、`game/tl/zh_hans/` 或 `game/mods/` 根目录的同名脚本及 `.rpyc`。卸载散装版本时删除 `game/mods/cookie_jar_unlock/` 中的脚本及编译文件。

首次打开图鉴时，先关闭游戏原有的介绍弹窗，再点击右上角锁头。

解锁、恢复、不兼容提示及按钮说明随游戏语言设置切换：简体中文（`zh_hans`）显示中文，默认语言或没有对应翻译的其他语言使用英文后备文字。按钮说明会随当前模式切换。

## 持久化行为

Mod 只切换原生的 `persistent.cookies` 全解锁开关，不修改已看过/正常解锁的场景记录。再次点击恢复时，原本通过剧情解锁的内容保留，仅依靠全解锁开关可见的内容恢复锁定；期间正常获得的解锁也保留，不回滚剧情或覆盖记录快照。

全解锁状态在重启游戏后继续保留，按钮仍显示闭锁，可点击恢复。已经用旧版Mod或本体设置开启全解锁时，也会显示闭锁；点击即可恢复正常解锁。卸载前应先点击闭锁按钮恢复；仅删除脚本不会撤销已保存的全解锁设置。本体设置中的“解锁全部”与此按钮使用同一开关，因此会相互同步。

脚本保留原生屏幕定义及各设备变体，仅在原界面绘制后附加按钮；不维护角色名或场景 ID 清单。点击时检查图鉴接口，接口缺失时提示不兼容且不修改解锁数据。若未来更改屏幕名称，按钮可能不再出现；若保留字段却改变其语义，仍需重新适配。
